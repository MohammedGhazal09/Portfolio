A modern, responsive portfolio website showcasing my work as a Web Developer.

## ✨ Features

- **Responsive Design** - Optimized for all screen sizes
- **Dark/Light Mode** - Theme toggle with system preference detection
- **Glassmorphism UI** - Modern glass-effect styling with animations
- **Contact Form** - Real email sending via EmailJS with spam protection
- **Performance Optimized** - Lazy loading, code splitting, gzip/brotli compression
- **Smooth Animations** - Subtle scroll and hover animations

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript
- **Build Tool:** Vite with SWC
- **Styling:** Tailwind CSS + shadcn/ui (Radix-based components)
- **Animations:** tailwindcss-animate
- **Email:** EmailJS
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/MohammedGhazal09/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📦 Build

```bash
# Production build
npm run build

# Preview production build
npm run preview
```
